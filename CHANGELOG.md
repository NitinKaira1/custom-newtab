# Changelog

## 2.8.0
- Each wallpaper remembers its own dim, brightness, saturation, blur, fit, focus, vignette, tint and video settings ("Save per wallpaper").
- Choose which wallpapers take part in the slideshow; shuffle or in-order playback.

## 2.7.0
- Shortcut/bookmark open animation plays for a fixed time (default 2.5 s) while the site loads in a background tab.
## 2.6.0
- Screen-fill open animation (grows from the tile, shows the site logo).
## 2.5.0
- Visualizer reads real tab audio; Share-audio and demo modes.
- Bookmarks widget (grid, dock, list, folder tabs, Ctrl+K search).
- Compact wallpaper library window with live hover preview; clearer Day/Night picker; dropdown text fix.
## 2.4.0
- Reworked Move & resize (handles for resize/rotate, snapping, arrow-key nudge); collapsible settings with search and descriptions.
## 2.3.0
- Visualizer bars widget (bars, mirror, dots, wave, radial).
## 2.2.0
- Audio player widgets (bar, pill, circle, card, mini) for the tab that is playing.
## 2.1.0
- Themes, analog clock, layout/clock/search options, zen mode.
## 2.0.0
- Scenes, backup/import, weather, timer, calendar, countdown, quotes, command palette, glass styles, Lite mode.
## 1.0.0
- Video/image wallpapers, widgets, shortcuts.
